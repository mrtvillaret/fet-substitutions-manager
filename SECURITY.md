# Security Policy

Found a security problem? Please don't open a public issue — use the
**Security** tab of this repository ("Report a vulnerability"), or write to
mrtvillaret@gmail.com.

Only the current state of `main` is maintained: to get fixes, `git pull` and
rebuild.

---

Si trobes un problema de seguretat, no obris una incidència pública: fes servir
la pestanya **Security** del repositori, o escriu a mrtvillaret@gmail.com.
Només es manté la branca `main`.
