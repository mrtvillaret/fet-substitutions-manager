# Captures de pantalla

Aquesta carpeta conté les imatges referenciades als READMEs. Substitueix aquests
noms pels teus PNG (fets sempre amb la institució d'exemple, sense dades reals):

- `substitucions.png` — vista de substitucions diàries
- `vigilancies.png` — vista de vigilàncies / grups sense classe
- `planificador.png` — planificador d'exàmens

Amplada recomanada: ~1200 px. Evita mostrar noms reals de professorat o centres.
